# 🏠 Home Alone - Seu Mentor Digital

### 🚀 Sobre o PIT 
O **PIT** é uma disciplina prática onde desenvolvemos uma empresa fictícia e um produto tecnológico do zero. Este projeto simula o mercado de trabalho, envolvendo desde a concepção do modelo de negócio até a implementação técnica de um site ou aplicativo.

---

### 💡 O Problema e a Solução
Mudar-se para a primeira casa sozinho é um desafio que mistura liberdade com total desorientação. *Como lavar uma roupa delicada? Como trocar uma resistência de chuveiro?* O **Home Alone** nasceu para ser o mentor digital de quem está começando essa jornada. Nossa plataforma centraliza conhecimento prático e apoio emocional para novos moradores solos.

---

### 🛠️ Funcionalidades Principais

* 📖 **Guias Práticos:** Tutoriais em texto passo a passo sobre limpeza, manutenção doméstica e culinária básica.
* 🎥 **Conteúdo em Vídeo:** Demonstrações visuais rápidas para facilitar o aprendizado de tarefas complexas.
* 🤝 **Aba Comunidade:** Um fórum interativo para os usuários trocarem dicas, tirarem dúvidas e compartilharem experiências sobre a vida adulta.
* ✅ **Checklists de Mudança:** Listas de itens essenciais para não esquecer nada ao montar a nova casa.
